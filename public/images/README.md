# Folder Gambar Profile Agent

Silakan letakkan file gambar (misalnya `agent-profile.png` atau `agent-profile.jpg`) ke dalam folder ini.

Nantinya, Anda bisa memanggil gambar tersebut langsung dari kode React Anda dengan path absolut seperti ini:

```tsx
<img src="/images/agent-profile.png" alt="Agent Profile" />
```

Atau jika menggunakan komponen Avatar yang sudah ada di `App.tsx`:

```tsx
<AvatarImage src="/images/agent-profile.png" />
```
